# HelloWorld

A starter repository for learning and experimenting with GitHub.

## Getting Started

1. **Clone this repository:**
   ```bash
   git clone https://github.com/davechoij7/HelloWorld.git
   cd HelloWorld
   ```

2. **Make changes**, then commit and push:
   ```bash
   git add .
   git commit -m "Describe your changes"
   git push
   ```
